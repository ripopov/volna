`volna-trace` loads immutable [VTR](../vtr/README.md) recordings from local files, in-memory images, or [`volna-server`](../volna-server/README.md) through a common API. It exposes hierarchy metadata, complete signal histories, transaction tracks, and activity indexes, with shared memory budgeting and cooperative remote decoding. Hosts handle background execution, server connections, and packet transport; FST and Kanata recordings must be converted to VTR before loading. Initialize the VTR submodule before building, then run `cargo test --locked -p volna-trace --all-targets` from the repository root with the pinned Rust toolchain.
