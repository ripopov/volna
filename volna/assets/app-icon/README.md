# Volna application icon

`volna.svg` is the canonical vector artwork. The PNG, ICO, and ICNS files are
raster versions used by native window and executable icons. When changing the
artwork, regenerate every raster size from the SVG so the platform icons stay
consistent. `volna-mark.svg` uses the same Wave V silhouette and follows the
active theme in the welcome and start panels. Keep both SVGs in sync with
their copies in `docs/design-system/assets/`.
