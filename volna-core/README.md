`volna-core` provides toolkit-independent viewer state, interactions, and drawing commands for [Volna](../volna/README.md). It manages waveform, pipeline, table, and record-detail panels, derived signals, linked navigation, workspaces, and undo/redo over immutable recording data from [`volna-trace`](../volna-trace/README.md). Frontends translate input into commands, execute background loading requests, paint the resulting scenes, and handle windowing and filesystem I/O. From the repository root, run `cargo test --locked -p volna-core` with the pinned Rust toolchain; the tests run headlessly.
